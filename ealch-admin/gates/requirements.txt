# verbecc: template-based French conjugation (the conjugator named in the
# master build doc alongside mlconjug3). Chosen over mlconjug3 itself because
# mlconjug3's published PyPI package ships a pretrained scikit-learn model
# pickle that fails to unpickle against any scikit-learn newer than the one
# it was built with (a real, reproduced incompatibility, not a hypothetical
# one) — verbecc instead trains and caches its own small model locally on
# first run against whatever scikit-learn is installed, so it self-heals.
verbecc>=2.0,<3
