# b2.21 « Les négations combinées » : chapter opener artwork

Eleven images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/negations-combinees/`
- **Filenames, exactly:** `act01.jpg` … `act11.jpg` (the lesson already points at
  `lessons/negations-combinees/actNN.jpg`, so a different name renders nothing).
  The folder is `negations-combinees`, NOT `negation-avancee` (that is lesson 20 in B1).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle.
  Make the files first, then register them. This file does NOT touch
  lessonImages.ts.
- **Paul makes these himself in ChatGPT** (B2-BUILD-LOG, wave 0 item 6). Every
  prompt below stands alone: paste one in and it produces that act's picture
  without any other context. The house style block is repeated in full in each
  prompt on purpose.
- **No lettering of any kind** in any image, no close-up faces, and nothing that
  needs a caption to be understood. Letters, forms, tablets, screens, bills and
  signs appear: every one of them is BLANK.
- **The single visual metaphor is LE VIDE DESSINÉ**, an empty space outlined
  precisely by several marks, with one mark left outside: an empty frame
  outlined by three strips of tape (act 2), a tray where every block fits but
  one (act 5), a lamp that chooses what it lights (act 9). These conceptual
  images alternate with quiet human scenes (a flat inspection, a police office,
  a stairwell, a notary's study, a radio studio) so eleven pictures do not read
  as eleven diagrams.
