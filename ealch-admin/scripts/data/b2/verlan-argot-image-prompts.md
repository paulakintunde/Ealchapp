# b2.32 « Le verlan et l’argot d’aujourd’hui » : chapter opener artwork

Eleven images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/verlan-argot/`
- **Filenames, exactly:** `act01.jpg` … `act11.jpg` (the lesson already points at
  `lessons/verlan-argot/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle.
  Make the files first, then register them. This file does NOT touch
  lessonImages.ts.
- **Paul makes these himself in ChatGPT** (B2-BUILD-LOG, wave 0 item 6). Every
  prompt below stands alone: paste one in and it produces that act's picture
  without any other context. The house style block is repeated in full in each
  prompt on purpose.
- **No lettering of any kind** in any image, no close-up faces, and nothing that
  needs a caption to be understood. Phones, screens, books, boards, signs and
  speech bubbles appear: every one of them is BLANK. No gesture, clothing or
  setting that caricatures a group, a suburb or a youth culture.
- **The single visual metaphor is L’ÉCHELLE**: a slim warm ochre ladder with
  four rungs appears somewhere in every image (a library ladder, a painter's
  ladder, a ladder of shelves, a ladder drawn by light), because the lesson is
  about the four rungs of register. Quiet human scenes in Lyon and Marseille
  (acts 1, 3, 5, 7, 8, 10, 11) alternate with conceptual images (acts 2, 4, 6,
  9) so eleven pictures do not read as eleven diagrams.
