# b2.26 « Réunions et négociations » · chapter opener artwork

Eleven images, one per act, shown on the chapter card the pager draws before each act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/reunions-negociation/`
- **Filenames, exactly:** `act01.jpg` … `act11.jpg` (the lesson already points at `lessons/reunions-negociation/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in `ealch-v2/src/content/lessonImages.ts`. `require()` resolves statically, so a ref registered before its file exists breaks the bundle. Generate the files first, then register them. This file does NOT touch lessonImages.ts.
- Every prompt below stands alone: paste one into ChatGPT and it produces that act's picture without any other context. The house style block is repeated in full in each prompt on purpose.
- **No lettering of any kind** in any image, no close-up faces, and nothing that needs a caption to be understood: the opener already carries the act title and the promise line underneath.
- **One metaphor, the door left ajar:** a negotiation keeps the door neither shut nor flung open. Acts 1, 9 and 11 show an ajar door; the others alternate conceptual images (a token, shades, a scale, hinges) with quiet human scenes at tables, on the phone and on stairs, so eleven images do not read as eleven diagrams.
