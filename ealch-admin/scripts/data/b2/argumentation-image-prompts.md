# b2.23 « Argumenter » : chapter opener artwork

Eleven images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/argumentation/`
- **Filenames, exactly:** `act01.jpg` … `act11.jpg` (the lesson already points at
  `lessons/argumentation/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle.
  Generate the files first, then register them. This file does NOT touch
  lessonImages.ts.
- Every prompt below stands alone: paste one into ChatGPT and it produces that
  act's picture without any other context. The house style block is repeated in
  full in each prompt on purpose.
- **No lettering of any kind** in any image, no close-up faces, and nothing that
  needs a caption to be understood. Pages, screens, newspapers and banknotes appear:
  every one of them is BLANK.
- **The single visual metaphor is THREE GESTURES: take a side, prove it, answer the
  other side.** Flags, threads, scales, two letters and doors carry it; conceptual
  images (acts 2, 4, 5, 7, 8, 10) alternate with quiet human scenes (1, 3, 6, 9, 11)
  so eleven pictures do not read as eleven diagrams.
