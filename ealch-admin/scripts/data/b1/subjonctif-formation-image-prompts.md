# b1.14 « Le subjonctif présent : la formation » — chapter opener artwork

Eleven images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/subjonctif-formation/`
- **Filenames, exactly:** `act01.jpg` … `act11.jpg` (the lesson already points at
  `lessons/subjonctif-formation/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`. `require()` resolves statically, so a
  ref registered before its file exists breaks the bundle. Generate the files
  first, then register them. This file does NOT touch lessonImages.ts.
- Every prompt below stands alone: paste one into ChatGPT (or the Fal image
  script) and it produces that act's picture without any other context. The
  house style block is repeated in full in each prompt on purpose.
- **No lettering of any kind** in any image, no close-up faces, and nothing that
  needs a caption to be understood: the opener already carries the act title and
  the promise line underneath.
- **The single visual metaphor is LA FORME EST DÉJÀ LÀ, a shape lifted from
  somewhere else in the same frame.** Across the eleven images, one element is
  always taken from a place it already existed and set down where it is needed:
  a cut-out that fits a hole already in the wall, a stencil, a shadow that
  becomes a solid, a key already on the ring. Nothing in these images may suggest
  doubt, emotion or hesitation: this act of the course is about HOW the form is
  built, not about when it is used. The conceptual images (acts 2, 3, 5, 6, 9,
  10) alternate with quiet human scenes (acts 1, 4, 7, 8, 11) so eleven pictures
  do not read as eleven diagrams.
