# b1.06 « Le futur simple : les radicaux irréguliers » — chapter opener artwork

Eleven images, one per act, shown on the chapter card the pager draws before
each act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/futur-irregulier/`
- **Filenames, exactly:** `act01.jpg` … `act11.jpg` (the lesson already points
  at `lessons/futur-irregulier/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`. `require()` resolves statically, so a
  ref registered before its file exists breaks the bundle. Generate the files
  first, then register them. This file does NOT touch lessonImages.ts.
- Every prompt below stands alone: paste one into ChatGPT (or the Fal image
  script) and it produces that act's picture without any other context. The
  house style block is repeated in full in each prompt on purpose.
- **No lettering of any kind** in any image, no close-up faces, and nothing
  that needs a caption to be understood: the opener already carries the act
  title and the promise line underneath.
- **The single visual metaphor: a word cut in two.** Every conceptual image in
  this set shows one shape made of two parts, where the LEFT part changes from
  image to image and the RIGHT part is always the same six-notch bar. That is
  the lesson's reframe drawn rather than written: the stem moves, the ending
  never does. The human scenes (acts 1, 6, 10 and 11) alternate with the
  conceptual ones so eleven images do not read as eleven diagrams.
