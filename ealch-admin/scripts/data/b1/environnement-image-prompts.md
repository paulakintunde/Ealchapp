# b1.33 « L'environnement et la société » · chapter opener artwork

Eleven images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/environnement/`
- **Filenames, exactly:** `act01.jpg` … `act11.jpg` (the lesson already points at
  `lessons/environnement/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`. `require()` resolves statically, so a
  ref registered before its file exists breaks the bundle. Generate the files
  first, then register them. This file does NOT touch lessonImages.ts.
- Every prompt below stands alone: paste one into ChatGPT (or the Fal image
  script) and it produces that act's picture without any other context. The
  house style block is repeated in full in each prompt on purpose.
- **No lettering of any kind** in any image, no close-up faces, and nothing that
  needs a caption to be understood: the opener already carries the act title and
  the promise line underneath. Every sign, bin, bag, placard, tag and paper is BLANK.
- **No frightening disaster imagery.** The climate and pollution acts show
  change and haze calmly: no flames, no smoke plumes, no floods, no masks, no
  suffering animals. The tone is factual and quiet, like the lesson.
- **The single visual metaphor is ONE SMALL EVERYDAY ACTION AND ITS WIDER
  RIPPLE.** Act 1 states it outright (a drop and its rings carrying objects
  outward); every later image shows one small gesture (a bottle, a toaster, a
  seedling, a signature) inside the wider thing it belongs to (four countries, a
  repair café, a river, a town square). That is the lesson's reframe made
  visible: a word, like a gesture, never arrives alone. The conceptual images
  (acts 1, 2, 4, 6, 8) alternate with quiet human scenes (acts 3, 5, 7, 9, 10,
  11), so eleven pictures do not read as eleven diagrams.
