# c1.01 « Faire le point sur sa grammaire » : chapter opener artwork

Twelve images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/bilan-grammatical-c1/`
- **Filenames, exactly:** `act01.jpg` … `act12.jpg` (the lesson already points at
  `lessons/bilan-grammatical-c1/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle.
  Make the files first, then register them. This file does NOT touch
  lessonImages.ts.
- **Paul makes these himself in ChatGPT** (never Fal). Every prompt below
  stands alone: paste one in and it produces that act's picture without any
  other context. The house style block is repeated in full in each prompt on
  purpose.
- **No lettering of any kind** in any image, no close-up faces, and nothing that
  needs a caption to be understood. Charts, pages, clocks and boards appear:
  every one of them is BLANK (no numerals, no words).
- **The single visual metaphor is FAIRE LE POINT, the navigator's bearing.**
  A blank chart and a compass in act 1; pins in three colours throughout (sage
  green for « à produire », dusty slate blue for « à reconnaître », terracotta
  for « point faible »); the full chart with its dotted course in act 12.
  Conceptual images (acts 2, 4, 6, 8, 10, 12) alternate with quiet human
  scenes so twelve pictures do not read as twelve diagrams.
