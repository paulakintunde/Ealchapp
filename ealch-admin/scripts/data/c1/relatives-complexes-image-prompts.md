# c1.04 « Les relatives complexes » : chapter opener artwork

Eleven images, one per act, shown on the chapter card the pager draws before each
act’s first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/relatives-complexes/`
- **Filenames, exactly:** `act01.jpg` … `act11.jpg` (the lesson already points at
  `lessons/relatives-complexes/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle.
  Make the files first, then register them. This file does NOT touch
  lessonImages.ts.
- **Paul makes these himself in ChatGPT** (B2-BUILD-LOG, wave 0 item 6). Every
  prompt below stands alone: paste one in and it produces that act’s picture
  without any other context. The house style block is repeated in full in each
  prompt on purpose. Never generated with Fal.
- **No lettering of any kind** in any image, no close-up faces, and nothing that
  needs a caption to be understood. Documents, cards and the clock face appear:
  every one of them is BLANK.
- **Alt text:** each prompt’s « The subject is … » sentence, as for wave 1.
- **The single visual metaphor is LE MOBILE**: each piece of a hanging mobile
  hangs from one arm by its own thread, as a relative clause hangs on one noun.
  Acts 2, 3, 5, 7, 8, 9 and 10 show it directly (a cluster with a part picked
  out, a pendant on an empty ring, a knot found under a magnifying glass, a
  mobile inside a mobile, a sagging chain rebalanced); the human scenes (acts
  1, 4, 6 and 11: an archive, an attic room, a notary’s office, a restored
  station) carry a small mobile in the room, so eleven pictures do not read as
  eleven diagrams.
