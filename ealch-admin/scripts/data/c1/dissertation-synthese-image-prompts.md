# c1.10 « Dissertation et synthèse » : chapter opener artwork

Twelve images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/dissertation-synthese/`
- **Filenames, exactly:** `act01.jpg` … `act12.jpg` (the lesson already points at
  `lessons/dissertation-synthese/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle.
  Generate the files first, then register them. This file does NOT touch
  lessonImages.ts.
- Every prompt below stands alone: paste one into ChatGPT and it produces that
  act's picture without any other context. The house style block is repeated in
  full in each prompt on purpose. The « The subject is » sentence of each prompt
  becomes its alt text.
- **No lettering of any kind** in any image, no close-up faces, and nothing that
  needs a caption to be understood. Sheets, letters, boards and game boxes appear:
  every one of them is BLANK.
- **The single visual metaphor is THE FOLD.** A subject is a sheet folded on itself:
  the crease is the tension; the plan unfolds it panel by panel; each transition is
  a crease or a hinge; the conclusion lays it flat and lifts one corner; a synthèse
  folds several sheets into one; the essay is a folded letter sent to someone. Every
  picture holds one folded or unfolding cream sheet. Conceptual images (acts 2, 3,
  5, 7, 8, 10) alternate with quiet human scenes (acts 1, 4, 6, 9, 11, 12) so twelve
  pictures do not read as twelve diagrams.
