# c1.05 « L’ellipse et la reprise » : chapter opener artwork

Twelve images, one per act, shown on the chapter card the pager draws before each
act’s first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/ellipse-reprise/`
- **Filenames, exactly:** `act01.jpg` … `act12.jpg` (the lesson already points at
  `lessons/ellipse-reprise/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle.
  Make the files first, then register them. This file does NOT touch
  lessonImages.ts.
- **Paul makes these himself in ChatGPT** (B2-BUILD-LOG, wave 0 item 6). Every
  prompt below stands alone: paste one in and it produces that act’s picture
  without any other context. The house style block is repeated in full in each
  prompt on purpose.
- **No lettering of any kind** in any image, no close-up faces, and nothing that
  needs a caption to be understood. Screens, papers, notices and labels are BLANK.
- **The alt text** for each image is the sentence that starts « The subject is » at
  the end of its scene.
- **The single visual metaphor is LE FIL**, one terracotta thread sewn through a
  text: where something is picked up, the thread comes back to the surface; where
  something is left unsaid, it runs behind the cloth, unseen and unbroken; where a
  pronoun could mean two things, two threads cross into a tangle. Conceptual images
  (acts 2, 3, 5, 7, 10) alternate with quiet human scenes (acts 1, 4, 6, 8, 9, 11,
  12), each carrying the same thread.
