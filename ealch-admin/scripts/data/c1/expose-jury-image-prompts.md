# c1.09 « L’exposé et le jury » · chapter opener artwork

Twelve images, one per act, shown on the chapter card the pager draws before each act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/expose-jury/`
- **Filenames, exactly:** `act01.jpg` … `act12.jpg` (the lesson already points at `lessons/expose-jury/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in `ealch-v2/src/content/lessonImages.ts`. `require()` resolves statically, so a ref registered before its file exists breaks the bundle. Generate the files first, then register them. This file does NOT touch lessonImages.ts.
- Every prompt below stands alone: paste one into ChatGPT and it produces that act's picture without any other context. The house style block is repeated in full in each prompt on purpose.
- **No lettering of any kind** in any image, no close-up faces, and nothing that needs a caption to be understood: the opener already carries the act title and the promise line underneath.
- **One metaphor, the thread:** a candidate holds one question from the dossier to the last answer. Every image carries one warm ochre thread or string: bundles left unjoined (act 1), threads that cross, braid and come out of a tangle (acts 3 to 5), a guided crossing (act 6), the jury pulling on it (a kite in the wind, pegs that push it aside, acts 9 and 10), a knot (act 11). Conceptual images alternate with quiet human scenes in an examination room, so twelve images do not read as twelve diagrams.
- Each prompt's « The subject is » sentence is the image's alt text.
