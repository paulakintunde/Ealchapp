# c1.02 « Le passé antérieur » : chapter opener artwork

Twelve images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/passe-anterieur/`
- **Filenames, exactly:** `act01.jpg` … `act12.jpg` (the lesson already points at
  `lessons/passe-anterieur/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle.
  Make the files first, then register them. This file does NOT touch
  lessonImages.ts.
- **Paul makes these himself in ChatGPT** (B2-BUILD-LOG, wave 0 item 6). Every
  prompt below stands alone: paste one in and it produces that act's picture
  without any other context. The house style block is repeated in full in each
  prompt on purpose. Never generated with Fal.
- **No lettering of any kind** in any image, no close-up faces, and nothing that
  needs a caption to be understood. Books, letters, notebooks and sheets of
  notes appear: every page is BLANK.
- **Alt text:** each prompt's « The subject is … » sentence is the alt line.
- **The single visual metaphor is LE RELAIS**, the baton handed over: an action
  let go of at the very moment the next one sets off. Conceptual images (acts 2,
  4, 6, 9) show a handover, two doors, dominoes and landings; quiet human scenes
  (acts 1, 3, 5, 7, 8, 10, 11, 12) show reading, retelling and the moments the
  passé antérieur describes, and the baton returns in act 12, so twelve pictures
  do not read as twelve diagrams.

## The house STYLE block

Verbatim from `ealch-admin/scripts/gen-rythme-images.mjs` (as in
`../b2/lecture-critique-image-prompts.md`), and repeated in full at the end of
every prompt below so each one stands alone:
