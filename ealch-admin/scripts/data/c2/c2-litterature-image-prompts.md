# c2.02 « L'analyse littéraire intégrale » : chapter opener artwork

Nine images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/c2-02-analyse-litteraire/`
- **Filenames, exactly:** `act01.jpg` … `act09.jpg` (the lesson already points at
  `lessons/c2-02-analyse-litteraire/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle. Paul
  draws the images himself in ChatGPT from the prompts below, drops them in the
  folder, then registers them, once, by script (B1-BUILD-PLAYBOOK.md §6.19). This
  file does NOT touch `lessonImages.ts` and no image was generated by the author
  of this draft.
- Every prompt below stands alone: paste one into ChatGPT and it produces that
  act's picture without any other context. The house style block is repeated in
  full in each one, on purpose.
- **No lettering of any kind** in any image, no close-up faces, nothing that needs
  a caption to be understood: the opener already carries the act title and the
  promise line underneath.
- **The single visual metaphor is LES QUATRE FILS** (the lesson's reframe:
  "reading a work means holding four threads together"). A small loom or a
  tapestry-in-progress, with four distinct thread colours drawn from the house
  palette itself: dusty slate blue (le registre), terracotta (la voix), warm
  ochre (la structure), sage green (la figure). The same four colours recur,
  in the same role, across all nine images, so a reader who sees several
  openers in a row can tell the threads apart without a caption. Conceptual
  loom/tapestry images (acts 1, 2, 4, 5, 6, 7, 8) alternate with quiet human
  scenes where a small loom or tapestry swatch appears as an object in the
  room (act 3, act 9).
