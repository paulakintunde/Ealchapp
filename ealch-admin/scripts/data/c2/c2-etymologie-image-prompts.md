# c2.05 « Étymologie et formation des mots » : chapter opener artwork

Ten images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/c2-05-etymologie/`
- **Filenames, exactly:** `act01.jpg` … `act10.jpg` (the lesson already points at
  `lessons/c2-05-etymologie/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle. Paul
  draws the images himself in ChatGPT from the prompts below, drops them in the
  folder, then registers them, once, by script (B1-BUILD-PLAYBOOK.md §6.19). This
  file does NOT touch `lessonImages.ts` and no image was generated by the author
  of this draft.
- Every prompt below stands alone: paste one into ChatGPT and it produces that
  act's picture without any other context. The house style block is repeated in
  full in each one, on purpose.
- **No lettering of any kind** in any image, no close-up faces, nothing that needs
  a caption to be understood: the opener already carries the act title and the
  promise line underneath.
- **The single visual metaphor is THE STONE** (the lesson's reframe: "behind
  every learned word sleeps an ancient stone"). A small, smooth, rounded stone,
  carved with a few soft abstract marks suggesting old letterforms (never a real
  readable alphabet), in a warm sandstone-to-terracotta colour. Recognising a
  root is spotting a stone; knowing where it really came from, rather than
  where it looks like it came from, is the other half of the lesson. Conceptual
  stone images (acts 2, 3, 4, 5, 6, 7, 9) alternate with quiet human scenes
  where the same stone appears as a small object in the room (acts 1, 8, 10).
