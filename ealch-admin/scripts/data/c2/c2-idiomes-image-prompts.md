# c2.03 « Cent expressions idiomatiques avancées » : chapter opener artwork

Twelve images, one per act, shown on the chapter card the pager draws before
each act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/c2-03-cent-idiomes/`
- **Filenames, exactly:** `act01.jpg` … `act12.jpg` (the lesson already points at
  `lessons/c2-03-cent-idiomes/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle. Paul
  draws the images himself in ChatGPT from the prompts below, drops them in the
  folder, then registers them, once, by script. This file does NOT touch
  `lessonImages.ts` and no image was generated by the author of this draft.
- Every prompt below stands alone: paste one into ChatGPT and it produces that
  act's picture without any other context. The house style block is repeated in
  full in each one, on purpose.
- **No lettering of any kind** in any image, no close-up faces, nothing that needs
  a caption to be understood: the opener already carries the act title and the
  promise line underneath.
- **The single visual metaphor is THE KEY AND ITS LOCK** (the lesson's reframe:
  an idiom carries a register as much as a picture, and only the lock whose
  FINISH matches the key's own actually opens). Every act's key is cut with one
  small emblem for that family's image (a crown for power, a mask for cunning,
  a balance for judgement, an overflowing cup for excess, a mirror for
  reputation, a die for fate, an hourglass for time, a ribboned quill for
  speech, a flame for ambition, a closed door for solitude); the SAME key is
  shown approaching two or three lock-plates of different finish (plain worn
  wood, polished brass, veined marble), and only one lock, matching the key's
  own finish, is shown open or glowing faintly. Acts 1 and 12 close the frame:
  act 1 shows a key that opens the wrong lock; act 12 shows a ring of several
  different keys, each already fitted to its own matching lock.
