# c2.08 « La production orale spontanée » : chapter opener artwork

Eight images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/c2-08-production-spontanee/`
- **Filenames, exactly:** `act01.jpg` … `act08.jpg` (the lesson already points at
  `lessons/c2-08-production-spontanee/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle. Paul
  draws the images himself in ChatGPT from the prompts below, drops them in the
  folder, then registers them, once, by script (B1-BUILD-PLAYBOOK.md §6.19). This
  file does NOT touch `lessonImages.ts` and no image was generated by the author
  of this draft.
- Every prompt below stands alone: paste one into ChatGPT and it produces that
  act's picture without any other context. The house style block is repeated in
  full in each one, on purpose.
- **No lettering of any kind** in any image, no close-up faces, nothing that needs
  a caption to be understood: the opener already carries the act title and the
  promise line underneath.
- **The single visual metaphor is THE ON-AIR LAMP** (the lesson's reframe: "live
  does not wait for you to be ready"). A small, warm, steadily glowing round lamp,
  the kind a radio studio keeps lit while the microphone is open, in a soft ochre
  to terracotta glow. It never switches off and nobody pauses it; every image asks
  what happens to the figures, the thread or the path WHILE it keeps glowing.
  Conceptual lamp-and-thread images (acts 2, 3, 4, 5, 6) alternate with quiet
  studio scenes where the same lamp sits as a small object in the room (acts 1, 7,
  8).
