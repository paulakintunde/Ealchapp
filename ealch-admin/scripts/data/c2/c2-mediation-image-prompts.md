# c2.06 « La médiation linguistique » : chapter opener artwork

Eight images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`).

- **Where the files go:** `ealch-v2/assets/lessons/c2-06-mediation/`
- **Filenames, exactly:** `act01.jpg` … `act08.jpg` (the lesson already points at
  `lessons/c2-06-mediation/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle. This
  file does NOT touch `lessonImages.ts` and no image was generated by the author
  of this draft; Paul draws the images himself from the prompts below, drops
  them in the folder, then registers them, once, by script.
- Every prompt below stands alone: paste one into an image generator and it
  produces that act's picture without any other context. The house style block
  is repeated in full in each one, on purpose.
- **No lettering of any kind** in any image, no close-up faces, nothing that
  needs a caption to be understood: the opener already carries the act title
  and the promise line underneath.
- **The single visual metaphor is THE DOOR** (the lesson's reframe: "the
  meaning never shrinks; only the door it passes through changes size"). A
  single warm-toned, rounded parcel or sealed object represents the meaning
  that must pass through, unchanged in size, from act to act. Doorframes of
  different widths and shapes around it represent the three levers
  (register, sentence length, technical-term treatment). Conceptual door
  images (acts 2, 4, 5, 6) alternate with quiet human scenes where the same
  parcel sits on a desk or is held up to a doorframe (acts 1, 3, 7, 8).

## The house STYLE block

Verbatim from `ealch-admin/scripts/gen-rythme-images.mjs`, repeated at the end of every prompt below:

> Flat editorial vector illustration, in the style of a modern French language textbook. Muted warm palette: cream and bone backgrounds, dusty slate blue, terracotta, warm ochre, sage green. Soft rounded geometric figures with simple calm faces, no black outlines, gentle flat shading. Subtle paper grain texture over the whole image. Warm even light. No text unless explicitly described.
