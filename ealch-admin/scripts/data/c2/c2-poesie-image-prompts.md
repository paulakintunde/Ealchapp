# c2.07 « Traduire la poésie » : chapter opener artwork

Six images, one per act, shown on the chapter card the pager draws before each
act's first mission (`LessonAct.opener.imageRef`). Deliberately fewer than
c2.02's nine, matching this lesson's optional-enrichment, kept-modest scope.

- **Where the files go:** `ealch-v2/assets/lessons/c2-07-poesie/`
- **Filenames, exactly:** `act01.jpg` … `act06.jpg` (the lesson already points at
  `lessons/c2-07-poesie/actNN.jpg`, so a different name renders nothing).
- **Format:** landscape 4:3, JPEG.
- **Before anything renders:** each ref must be registered in
  `ealch-v2/src/content/lessonImages.ts`, with alt text. `require()` resolves
  statically, so a ref registered before its file exists breaks the bundle.
  Paul draws the images himself in ChatGPT from the prompts below, drops them
  in the folder, then registers them, once, by script (B1-BUILD-PLAYBOOK.md
  §6.19). This file does NOT touch `lessonImages.ts` and no image was
  generated by the author of this draft.
- Every prompt below stands alone: paste one into ChatGPT and it produces that
  act's picture without any other context. The house style block is repeated
  in full in each one, on purpose.
- **No lettering of any kind** in any image, no close-up faces, nothing that
  needs a caption to be understood: the opener already carries the act title
  and the promise line underneath.
- **The single visual metaphor is LA TRAVERSÉE** (the lesson's reframe:
  "translating a poem is a crossing; you cannot carry all your luggage to the
  other shore"). A small boat crossing calm water between two riverbanks,
  with four small cloth bundles (bagages) in the house palette: terracotta
  (le ton), dusty slate blue (le rythme), sage green (l'image), warm ochre
  (le sens littéral). The same four colours recur, in the same role, across
  all six images, so a reader who sees several openers in a row can tell the
  bagages apart without a caption. Conceptual boat-and-shore images (acts 1,
  2, 4, 5) alternate with quiet human scenes where the boat or a bundle
  appears as an object in the room (acts 3 and 6).
