EALCH · DESIGN AUDIT · v2
State of the design.
Covers all 20 screens, now including Smart Review, Placement, Dictation, Downloads and the dictionary popover added in v2.
GOOD
Working well
Consistent visual system
One accent teal, Instrument Serif italic for headlines, dark radial-gradient backdrops on every screen. It reads as one considered product, not a stitched-together prototype.
Speaking-first practice loop
Role Play, Speak Mode, Voice Flash cover output, not just recognition — rare in language apps and the app's clearest differentiator.
New Smart Review closes the loop
Pulling misses from Role Play, Coach, and quizzes into one queue is the single most important structural fix — mistakes now have somewhere to go.
Feedback report has real substance
Trajectory, confidence, replay — it treats a conversation as data worth reviewing, not just a pass/fail.
Bilingual UI done properly
Every string branches on FR/EN rather than hard-coding one language — genuinely dual-audience, not just decoration.
IMPROVE
Needs work
Home is getting crowded
Streak card, Review entry, word-of-the-day, hero, 4 foundations tiles, Role Play, Dictée, playlists, exams, weak spots — 9+ sections stacked before any real hierarchy. Needs a "your day" fold above everything else, with lower-priority browse content collapsed under a see-more.
Settings screen is one long scroll
Subscription, currency, app language, appearance, sound, reminders, downloads, accent, sign out — nine sections with no grouping or section jump. Split into Account / Learning / Notifications / Appearance sub-pages, or at minimum add sticky section headers.
Five near-identical practice-mode cards
Flashcards, Voice Flash, Sentence Builder, Role Play, Dictée all use the same tile pattern with a one-line subtitle — a new user can't tell which to pick first, or how they differ in difficulty/purpose. Needs a clearer "what happens when I tap this" signal, maybe grouped by skill (listening / speaking / writing).
Streak card duplicates the tab bar's Home entry
It's the first thing under the greeting but visually similar in weight to the hero directly below it — two hero-strength moments compete for the same glance.
Pricing card copy is thin
"Unlimited Examiner · Advanced reports · Offline" vs. free's three bullets — no comparison table, no framing of what's actually lost by staying free. The upgrade moment is under-sold given how much of the app it gates (Offline, Examiner).
No empty / error / loading states designed
Every screen assumes happy-path data (cards always exist, mic always works, AI always responds instantly). Worth designing: empty review queue ("all caught up"), offline/no-mic states, coach response delay.
REMOVE
Cut or rethink
Redundant settings gear icon everywhere
Every practice-mode header repeats a settings gear that just opens the same global Settings screen mid-exercise — an odd escape hatch that breaks focus during a drill. Drop it from in-session headers; keep Settings reachable only from Home/Profile.
Accent-region picker's payoff is unclear
Settings lets you pick a regional accent, but no other screen explains what changes (voice model? vocabulary? both?). Either surface the effect somewhere the user will notice it, or fold it into onboarding instead of a standalone Settings section.
Two navigation entries into Le Coach chat
Chat lives in the tab bar and the hero card also opens a coach-adjacent Speak Mode — worth confirming these are meant to be different features, since visually they look like the same idea reached two ways.
"Test alarm" button in Settings
A debug-flavored affordance in a shipped settings panel. Fine to keep functionally, but restyle so it doesn't read as a leftover dev tool.
Onboarding is 10 steps before any payoff
Goal, experience, pace, calibration, etc. all collected before the user hears/speaks a word of French. Worth cutting to the 3–4 questions that actually change the curriculum, and moving the rest into the new placement test instead.
If I fixed three things next
1. Re-tier the Home feed
One compact "today" strip (streak + review count), then the hero, then everything else collapsed under tabs or a "browse" fold.
2. Group Settings into sections
Account & Billing / Learning / Notifications / Appearance — even as in-page anchors, before it becomes a scrolling wall.
3. Differentiate the five drills
Label each tile by skill (Read / Listen / Speak / Write) so the choice is legible, not five lookalike cards.
