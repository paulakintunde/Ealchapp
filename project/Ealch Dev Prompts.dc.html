Dev prompt — Ealch v2 App (React Native + Expo) · Master spec
{{ copyCLabel }}
You are a senior React Native architect and engineer. Build **Ealch v2** — an AI French voice-coach mobile app — with **Expo**. The design is final and fully specified below (it mirrors approved hi-fi mockups). Do not improvise visuals; implement to spec. Follow the phased plan in section 16: the top priority is that the EARLIEST build is fully functional end-to-end, with features layered on top of that working core — never a broad, half-wired skeleton.

═══════════════════════════════════════════
1 · PRODUCT SUMMARY
═══════════════════════════════════════════
Ealch teaches spoken French through an elegant, editorial, dark-UI experience and an AI coach persona named **Camille**. Core loop: micro-lessons + flashcards with spaced repetition + live spoken conversation with AI feedback ("Le Rapport").
- UI languages: **English and French** at launch (user-switchable, independent of the course being studied). Architecture must support adding more UI locales and more target-language courses later — French is course #1.
- A separate remote Ops Console ("**Ealch Admin**", built as its own project) manages users, billing, content publishing, AI model routing, feature flags, notifications, and releases. This app must READ all of that from the backend at runtime — content, flags, and model routing change without an app release.

═══════════════════════════════════════════
2 · TECH STACK
═══════════════════════════════════════════
- Expo SDK (latest stable) + EAS Build/Update. TypeScript strict. Targets: iOS, Android, Web (expo web — gate native-only features gracefully with capability checks, never crashes).
- Navigation: **Expo Router** (typed routes). State: **Zustand** (+ persist via MMKV). Styling: **NativeWind v4** with the design tokens in section 4 as the Tailwind theme.
- Animation/gesture: react-native-reanimated + react-native-gesture-handler ONLY (no Animated API mixing).
- Audio: expo-audio for playback and recording; expo-speech-recognition for on-device STT; expo-speech as TTS fallback.
- Offline: expo-sqlite + drizzle-orm (structured cache + SRS store), expo-file-system (audio/media downloads).
- Platform: expo-notifications, expo-haptics, expo-secure-store, expo-localization.
- Backend: **Supabase** — Auth (email/password + Sign in with Apple + Google), Postgres (RLS on everything), Storage (audio assets), Edge Functions (all AI proxying + report generation).
- Subscriptions: **RevenueCat** (react-native-purchases).
- Analytics: PostHog. Crash reporting: Sentry. Both behind adapters (section 3).

═══════════════════════════════════════════
3 · SWAPPABILITY — PORTS AND ADAPTERS (non-negotiable)
═══════════════════════════════════════════
Every external dependency sits behind a TypeScript interface ("port") in src/core/ports/. App code imports the port, never a vendor SDK. A registry binds adapters at startup; bindings can be overridden by remote config where safe.

Ports:
- LLMPort — chat(messages, opts) streaming + complete(); used by Speak Mode, Le Coach, feedback, placement, dictation scoring, sentence validation.
- TTSPort — synthesize(text, voice, speed) → audio; voice catalog per accent.
- STTPort — live transcription stream + file transcription; returns timestamps + confidence.
- PronunciationPort — score(audio, referenceText) → per-word/phoneme scores.
- PaymentsPort, AnalyticsPort, PushPort, CrashPort.
- ContentPort — versioned course/lesson/deck fetch + delta sync.
- ConfigPort — remote config + feature flags, cached offline, refreshed on foreground.

Default adapters (each replaceable by writing one file):
- LLM: Anthropic Claude via Supabase Edge Function proxy. NEVER ship AI API keys in the client — every AI call goes through an edge function that checks auth + entitlement + rate limits.
- TTS: ElevenLabs via edge proxy, cached in Storage by content hash; fallback expo-speech on-device.
- STT: native expo-speech-recognition where available; fallback Whisper via edge proxy.
- Pronunciation v1: STT transcript + LLM rubric scoring (structured JSON out). Upgrade path: dedicated phoneme API — same port.
- Payments: RevenueCat. Analytics: PostHog. Push: Expo Push.
Model routing per capability (chat, feedback, placement, dictation…) is read from remote_config — the Ealch Admin "AI Models" screen edits it; new sessions pick it up within ~60 s.

4 · DESIGN SYSTEM (exact)
═══════════════════════════════════════════
Fonts (bundle locally via expo-font): **Instrument Serif** (400 + italic — display/headlines) and **Instrument Sans** (400/500/600/700 — everything else).
Tokens (dark UI only at launch):
  --bg:      #0B0C0E   app background
  --bgDeep:  #060708   speak mode / deepest surfaces
  --card:    #101216   cards        --card2: #14171C  raised cards
  --sheet:   #13161B   bottom sheets  --input: #111318  inputs
  --tx:      #F4F2ED   primary text (cream)
  --accInk:  #0B100F   text on accent
  --acc:     user-selected accent. Options exactly: #2FD6C1 (default teal), #FF6B5C coral, #D9B36C gold, #8FA7FF periwinkle. Chosen in onboarding step 02, changeable in Profile; flows through the ENTIRE app via the theme provider.
Derived tints: use opacity/blend of --tx, #FFFFFF and --acc (e.g. text-60%, hairlines white-10%, accent-14% radial glows at the top of most screens).
Type scale: serif italic display 42–76px (screen titles like "Parlez avec élégance."); serif 34px section titles; overline labels 10–12px, letter-spacing 0.28–0.46em, weight 600, 40%-cream; body 13–15px; metadata 11–12px 50%-cream.

Icons: inline SVG, 1.5–1.7px stroke, round caps, drawn minimal — no icon fonts, no emoji.
Motion vocabulary (recreate with Reanimated): fadeUp (14px rise, 0.4–0.5s ease) on screen entry; fadeIn 0.3s for overlays; pulseRing (expanding accent ring) on live mic; spinRing loader; blinkDot typing/loading dots; ewave equalizer bars scaleY when audio plays; auraDrift slow breathing glow behind Camille in Speak Mode; logoPop spring on splash. 60fps, UI-thread driven.
Haptics (expo-haptics): light impact on all primary taps + card flips; medium on deck answer buttons; success notification on deck-complete / lesson-complete / streak; warning on errors; selection ticks on pickers and sliders.

6.7 FLASHCARDS — deck screen, progress bar + n/m count; card flips in 3D on tap (FRANÇAIS front / ANGLAIS back, serif); audio button per side; answer buttons "Encore" (again) and "Je sais" (got it) drive the SRS; deck-done screen with serif score (e.g. 7/10), "Missed cards return tomorrow — right before you'd forget them.", Replay/Back.
6.8 VOICE FLASH — spoken flashcards: prompt shown, user speaks the answer, STT + fuzzy match grades it, pronunciation feedback chip, same SRS wiring.
6.9 SENTENCE BUILDER — word-tile assembly: tap/drag shuffled tiles into a sentence, validate (exact match; LLM explains errors), streak counter, haptic feedback per tile.
6.10 ROLE PLAY — scenario dialogue (e.g. café, taxi) with a Vocab Injector panel: "Use each at least once — Camille is listening." Target phrases get checked off as detected in the user's speech; scene transcript; end summary.
6.11 SMART REVIEW — SRS dashboard: due-today count, forecast, weak-points list ("7 errors this week", "pronunciation · 5 errors"), "Ask Camille why →" deep-links into Le Coach with context. Start-session CTA.
6.12 REVIEW SESSION — mixed-modality queue (flash, voice, sentence) served by the scheduler; per-item grading; session summary.
6.13 TRACK PLAYER — micro-lesson audio player: playlists ("Pronunciation Deep-Dives · 15 tracks · nasal vowels", "Casual Parisian Slang", "French for Business", "Audio Degradation · Métro"), artwork block, scrubber, speed cycle (0.8/1.0/1.2×), skip ±15s, queue, background audio + lock-screen controls, equalizer bars animate while playing.
6.14 SPEAK MODE — the signature screen. bgDeep, drifting accent aura behind a large orb; states: idle → listening (pulseRing on mic, live partial transcript) → Camille thinking (blinkDot) → Camille speaking (TTS + aura animates). Full-duplex conversation loop: STT stream → LLM (Camille persona: warm, exacting, corrects in context, adapts to the user's level + chosen accent) → TTS. Tap-to-interrupt. Session transcript retained; "End session" → generates Feedback Report.
6.15 FEEDBACK — LE RAPPORT — post-session report: overall serif score, category bars (pronunciation, grammar, vocabulary, fluency), error list with corrections + replay of the user's own audio moment, recommended drills that deep-link (deck/lesson/builder). Generated by an edge function from the transcript (structured JSON), stored in history.
6.16 CHAT — LE COACH — text chat with Camille: streaming replies, tappable corrections on user messages, suggestion chips, French words long-pressable → Dictionary. Same LLMPort + persona as Speak Mode.
6.17 PLACEMENT TEST — adaptive: reading/listening/speaking items, difficulty adapts per answer, ends with CEFR level (A1–B2) → sets level, unlocks tracks, seeds the review queue.
6.18 DICTATION — plays a French sentence (TTS or recorded), user types what they hear; diff-highlighted correction (per-word), replay + slow replay, scoring streak.
6.19 PROFILE — avatar, name, level badge, streak stats, weekly minutes chart, accent-color picker, settings entry, subscription status card.
6.20 SETTINGS — UI language (EN/FR), course accent voice, daily reminder time, notification toggles (daily alarm / weekly report / nudges), audio quality, downloads entry, account (email, password, sign out, delete account), legal.
6.21 OFFLINE DOWNLOADS — storage map (Audio 690 MB / Lessons / Decks 160 MB visual bar), rows with states: SAVED ✓ / downloading 64% / GET ↓ / AUTO (Smart Review queue syncs each morning). Pause/resume/delete; wifi-only toggle.
6.22 DICTIONARY OVERLAY — bottom sheet over dimmed blur: word, IPA, TTS play, senses, example w/ translation, "add to deck" action. Available from any French text via long-press.
