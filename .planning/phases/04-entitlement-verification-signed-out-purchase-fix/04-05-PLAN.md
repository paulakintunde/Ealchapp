<objective>
Build and deploy `start-exam-attempt` — the server-side trust boundary for exam access (D-05). It re-derives the entire gate decision from server-held facts and, when the decision is "allowed", writes the authorized attempt row that `grade-exam` will later trust.

Purpose: D-03 confirmed `grade-exam` has zero entitlement check today. D-05 puts the check at START, not at grade time, so a subscription lapsing mid-épreuve cannot void a sitting already underway. This function is that check.

**The single highest-risk mistake available in this phase, spelled out:** a gate that asks only "does this uid hold `'examiner'`?" would reject 100% of live exam attempts the moment it ships, because `system_config.config.examGateOn` is `false` in production (the exam tier ships fully open) and nobody holds the `'examiner'` entitlement yet. This function MUST compute the full four-input `examPaperAllowed()` decision — `gateOn`, `entitled`, `freePapers`, `paperNo` — exactly as the client does. Task 2's parity test is what keeps it that way permanently.

Output: a new Deno edge function, a source-text parity test binding its duplicated decision function to the client's canonical one, a SETUP.md deploy entry, and the function deployed to production with curl-proven auth behavior.

THE DECISION FUNCTION TO DUPLICATE VERBATIM — ealch-v2/src/utils/examGate.logic.ts:
```typescript
export type GateDecision =
  | { allowed: true }
  | { allowed: false; reason: 'needs-exam-tier' };

export function examPaperAllowed(input: {
  gateOn: boolean;
  entitled: boolean;
  freePapers: number;
  paperNo: number;
}): GateDecision {
  const { gateOn, entitled, freePapers, paperNo } = input;
  // The gate is off: everything is open, whatever else is true.
  if (!gateOn) return { allowed: true };
  // Paid for it.
  if (entitled) return { allowed: true };
  // Inside the free allowance. Papers are numbered from 1, so an allowance of
  // 1 opens paper 1 and nothing else.
  if (paperNo <= Math.max(0, Math.floor(freePapers))) return { allowed: true };
  return { allowed: false, reason: 'needs-exam-tier' };
}
```
