# Phase 07.1: UI and UX audit (2026-09-24)

Done on the Pixel 6 dev client after the spine shipped. Screenshots are in `evidence/ux/` and `evidence/gap/`. The audit covers the den/trail, the Levels page, the act screen, the Fiche and pre-roll sheets, the lesson header, home, Profile, Speak, Coach and Settings.

## Fixed in this pass

| # | Area | Problem | Fix | Evidence |
|---|---|---|---|---|
| 1 | Act screen (B1) | The act's chapter art never appeared on the act screen, the first screen the trail opens. All 154 B1 acts carry art, and it only showed later, inside the lesson pager. | `act.tsx` draws `act.opener.imageRef` above the title. | `ux/04-act-screen-image` |
| 2 | Act screen | The mission counter read "13 / 7": the lesson-wide done set counted over the act's rows. | Counts done missions within the act (`actDone`). | `ux/05-act-counter` |
| 3 | Home hero | The top ~40% of the Continue card was an empty gradient. | Shows the resumed act's chapter art, fading into the card, with a scrim under the eyebrow. Lessons without art are unchanged. | `ux/07b-home-hero-art` |
| 4 | Profile | The avatar circle showed an initial or a person outline, never the avatar picked in Settings. This was **not a regression**: it was never wired. Every mascot render (home, Speak, Coach, narrated player, Settings picker) was checked and works. | Profile shows the chosen avatar. | code (`profile.tsx`) |
| 5 | Levels | Levels existed only as a small tag opening an overlay that needed a scroll at font scale 1.3. | A standalone **Levels page** (`ealch://levels`): badge, name, PREMIÈRE tag, units and % learned, progress bar, check on the current band. ## Found, not fixed (recommended next)

| Priority | Area | Finding |
|---|---|---|
| High | Floating dev "Tools" gear | It covers content on every screen (the trail's chevrons, sheet text). Dev-only, but it hides defects in every screenshot. Worth disabling in the dev client menu while testing. |
| Medium | Lesson header | The title truncates to "B1 · LEÇ…" beside the language chip, book, help and settings, so the header has five controls and no room for the lesson name. Move help and settings into one overflow, or put the title on its own line. |
| Medium | Home | The FR/EN toggle and the language chip in lessons both say "language" but control different things (UI language vs. lesson glosses). A learner can confuse them. Label one "App" and the other "Lesson English". |

| Low | Lesson overview page | Before mission 1, the overview has ~40% empty space above the title. The same chapter-art treatment as the home hero would fill it. |
| Low | Recap copy | The recap card's strings ("Where you were", "Pick up where you left off", "Ignore…") are hardcoded English in `ActCheckpoint.tsx`, not i18n. They predate this phase, but the French UI shows English there. |

## Features learners may miss (discoverability)

- **Unit info** (fixed, #7): it holds the A1 exam.
- **The Levels page** (fixed, #5 and #6).
- **Acte 00 · Narrated**: well placed at the top of each unit, but only its speaker glyph distinguishes it from an act. A one-line sub ("Listen first, 10 min") would say what it is.
- **"Vocab first"** on home primes the lesson's words, but only appears when there are new words. That's fine; recorded so it isn't mistaken for a bug.
- **Language control in lessons (B1+)**: the chip label states the mode ("French only"), which is good, but nothing says the mode can be changed. A chevron like the level chip's would signal it.
