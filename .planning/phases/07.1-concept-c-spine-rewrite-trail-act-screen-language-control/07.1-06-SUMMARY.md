## Back-handling mechanism

**`BackHandler` (`react-native`'s hardware-back event), not a route.** Both panels are local-state overlays — `open`/`onClose` props, mounted absolutely over whatever screen renders them — never `expo-router` routes, so the router's own back stack never sees them. This is the same bug class `sons-06-muettes.test.ts:484-491` records for a different overlay: without an explicit listener, Android's hardware back pops the SCREEN underneath the overlay instead of closing the overlay itself ("tapping 'See all 16 endings' and pressing back ejected the learner from the lesson rather than returning them to the grid they came from"). Each panel subscribes to `hardwareBackPress` only while `open` is true, calls `onClose()`, and returns `true` to swallow the event — mirroring `app/lesson.tsx:356-375`'s own pattern for its own local-state overlays.

This is deliberately NOT `SheetChrome.tsx`'s formSheet mechanism (plan 05): that component's own header names it as being for "every formSheet ROUTE this phase adds" (`fiche.tsx`, plan 09's pre-roll sheet). Making either panel here a formSheet route was considered and rejected, per this plan's own instruction, because the panel must stay an overlay and this plan must not touch `app/_layout.tsx`, which plan 05 owns and registers routes in — confirmed untouched: `git diff --exit-code $(git merge-base HEAD @{u} 2>/dev/null || echo HEAD~1)..HEAD -- ealch-v2/app/_layout.tsx` exits 0 for every commit in this plan.

## `theme.tsx` scope boundary (restated)

`app/theme.tsx:88-115`'s horizontal band-chip row is a **different control** from the Den's/trail's band selector this plan builds. It selects a band inside one theme's parcours (a different job, a different screen), not the Den/trail's own band selector, and this plan does not touch `theme.tsx`. It dodges D-07's 43.7px arithmetic a different way than `LevelPanel` does — `minHeight: 34` plus horizontal **scrolling**, so it is never dividing a fixed width in the first place — and after plan 03 it renders seven chips instead of six, which is in scope for plan 11's eyeball pass, not a redesign this plan owns.
