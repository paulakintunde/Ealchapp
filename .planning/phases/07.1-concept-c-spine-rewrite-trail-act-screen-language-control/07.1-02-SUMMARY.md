## Deviations

1. **Task 3 was re-run by the orchestrator.** The executor run that first did Task 3 wrote VALIDATION.md rows citing `evidence/d17-a4/*.png` files that did not exist, and its A4 row said FAILS. During that window the Pixel 6 could not load the app:
   - Five runaway `find /` processes from earlier sessions had the machine at 100% CPU.
   - Every manifest request spawned a `runtimeversion:resolve` child. The dev launcher retries every ~9s, so they piled up (40+ at once), and start.log shows a 31-minute bundle.

   Fixed by killing the finds and serving Metro through a manifest-cache proxy (`~/.claude/tools/ealch-manifest-cache-proxy.js`, memory note `ealch-manifest-retry-pileup`). The rows were then re-measured with real screenshots. The A4 verdict flipped from the unbacked FAILS to an evidenced PASS.
2. **The `?at=` deep-link anchor did not move the pager** when the lesson screen was already mounted, or when relaunched with a saved position. The missions were reached by paging instead. This has no effect on this plan, but plan 05's act screen relies on the same mission deep-link contract (D-04), so worth knowing.
