<the_44px_arithmetic>
D-07 is not a style preference and the plan should read it as arithmetic.

- Seven equal-flex columns in a 342px content width give **43.7px** each. The platform minimum is 44. That is the whole reason the pill row lost.
- The rejected shape is `den.tsx:122-138`: `flex: 1, minHeight: 44` across **three** tabs. At three it works. At seven it does not.
- `app/theme.tsx:88-115` dodges the arithmetic a different way: `minHeight: 34` plus **horizontal scrolling**, so the chips are not dividing a fixed width at all.
- A full-row panel divides nothing. Each row is the full content width and grows vertically with the font scale.

**Two guards in this suite say opposite things about 44px and they must not be cross-applied:**

| Guard | Rule | Applies here? |
|---|---|---|
| `sons-06-muettes.test.ts:472-482` | a 32px header control **must** carry `hitSlop={8}`, because *"32px is the visual size the header needs; without hitSlop the TOUCH target is 32 too, which is under the platform minimum"* | **Yes** for the chip that opens the panel |
| `subMission.logic.test.ts:432-437` | the sentence-chip row **must** be `flexGrow:0, flexShrink:0, height: 44` and explicitly **must not** be `minHeight: 44`, *"not a minimum, which let them grow with the row"* | **No.** That discipline is for a fixed chip strip. Panel rows contain scaling text and need `minHeight: 44` |

`den.tsx:129` already uses `minHeight: 44` on the current band tabs. That is the shape to carry over.

**Font scale 1.3 is a non-monotonic bug, so it is the value to test.** `type.logic.ts:63-85` records the measured Pixel 9 failure: display-role glyphs did not grow while the line box did, "A bientot !" rendered as "A", eight of nine cards in one deck lost text, and it is **absent at 1.0, 1.15 and 1.8 and present at 1.3**. `T.uSoon` (`'BIENTOT'` / `'SOON'`, `strings.ts:607`/`:1059`) is the string that already clipped. The device check is plan 11's; this plan's job is to not build a shape that cannot survive it: no `height:` on text, no `numberOfLines` on a band name, and the `maxScale` escape hatch (`Type.tsx:57-58`) only on the fixed-width chip, never on a panel row.
</the_44px_arithmetic>
