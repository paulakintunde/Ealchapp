# Phase 07.1 Plan 09: Acte 00, the Pre-roll Sheet, and the Paywall's Two Trail Positions Summary

**The paywall now sits in exactly two trail positions via one `TrailGateRow` component (a locked-band gate banner and the A1 boundary row, both routing to `/paywall?from=gate:levels`), the narrated lesson has a home on the trail as an acte 00 row that opens a pre-roll sheet (`app/preroll.tsx`, the same `formSheet` mechanism `fiche.tsx` uses) stating the real narration shape read from `flattenNarration`/`stageRanges`, and leaving that player now prefers `router.back()` over destroying the trail.**

## Accomplishments

- **`src/components/PremiereLockTag.tsx`** (D-34): the PREMIÈRE lock pill extracted from `flashthemes.tsx`'s canonical instance, byte-for-byte in style. Takes only `locked: boolean` (+ optional `size`); derives nothing — reads no store, calls no `useFeature`, imports no `FREE_BANDS`. The other five existing copies (`theme.tsx`, `flashthemes.tsx`, `dictationthemes.tsx`, `voicethemes.tsx`, `sentencethemes.tsx`) are deliberately untouched, confirmed via `git diff --exit-code` on all five. Used in `TrailRow.tsx` for both the act row's and the acte0 row's trailing icon (replacing a bespoke lock/chevron pair each), so the trail does not become a seventh copy.
- **`src/components/TrailGateRow.tsx`** (D-21/D-22/D-23): one component, two variants — `'gate'` (edge-to-edge via the `marginHorizontal: -24` bleed, pinned above a locked band's trail with the trail visible beneath it) and `'boundary'` (a bordered card at the end of the A1 trail). Both fire `trackEvent('gate_blocked', { feature: 'levels.all', from: 'den' })` then push `/paywall?from=gate:levels` — exactly one `'gate:levels'` string in the whole file, shared by both variants. Wired into `app/den.tsx`'s row dispatch, replacing plan 08's inline placeholder JSX for the `gate` and `boundary` row kinds.
- **`app/preroll.tsx`** (D-10/D-11/D-12/D-37): the acte 00 pre-roll sheet. Same `formSheet` mechanism as `app/fiche.tsx` (D-38's PASS verdict, one sheet mechanism in this phase, not two) — registered in `_layout.tsx` with the identical `sheetAllowedDetents: [0.55, 0.92]` / `sheetCornerRadius: 26` / `contentStyle: { backgroundColor: t.sheet }` shape. Param normalisation (`Array.isArray(params.key)`) and a dead-link guard (missing lesson OR a lesson with no `narration` at all both back out via `canGoBack()`-preferring exit) mirror `fiche.tsx`/`act.tsx`. The stated shape (`T.prerollShape` interpolated with stage count / spoken-passage count / mic-moment count) is computed from `flattenNarration(L.narration)` and `stageRanges(segs)` — the player's own source of truth — never a hardcoded number; `T.prerollMicNote` is rendered verbatim and never implies the mic opens on its own. The Start control closes the sheet (`router.back()`) then pushes `/narrated?key=<L.id>` — `app/narrated.tsx` itself is untouched by this file.
- **`app/den.tsx`**: `goActe0` now pushes `/preroll` instead of `/narrated` directly — acte 00's press always lands on the pre-roll sheet first on an unlocked band, and on a locked band routes straight to the paywall (unchanged from plan 08's `onLockedPress`).
- **D-41 — `app/narrated.tsx`'s exit path**: both `router.replace('/den')` call sites (the `done` screen's `FocusHeader onClose` and its "back to den" button) now call a shared `exit()` that prefers `router.canGoBack() ? router.back() : router.replace('/den')` — the same shape `fiche.tsx`/`act.tsx` already use. `git diff --stat` confirms a 10-line, 2-site change; the gate at L52-63, the never-auto-listen behaviour and the player body are otherwise byte-identical.
- **`src/content/spine-layout.test.ts`**: `PremiereLockTag.tsx`, `TrailGateRow.tsx` and `app/preroll.tsx` added to the named file list (now 10 files), extending the D-43/D-44/i18n-improvised-copy guard over every file this plan wrote.
- **`src/store/lockVisibilityWiring.test.ts`** and **`src/content/spine-routes.test.ts`**: extended with source-text assertions for the two trail positions, the locked-row disabled-but-mounted contract, `PAYWALL_COPY`'s unchanged 3-key set, and `preroll.tsx`'s param handling / dead-link guard / formSheet registration.
