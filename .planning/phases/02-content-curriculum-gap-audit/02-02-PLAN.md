**Step B — apply this coherence rubric.** RESEARCH.md Open Question 2 leaves
"coherent" undefined; this plan defines it, so the judgement is consistent and
auditable. A unit's pedagogical fields are COHERENT when all of:

  (a) `canDo` is non-null and non-empty.
  (b) `canDo` is a learner-facing capability statement, not a placeholder. Score
      it, do not regex it (model on `find-french-notes.ts`'s `frenchScore`
      shape). A canDo FAILS (b) if any of: it is under 20 characters; it does not
      start with a capability verb phrase (`Can `/`Peut `/an equivalent); it is
      the literal unit title or `sub` repeated verbatim; it contains a
      placeholder marker (`TODO`, `TBD`, `FIXME`, `SOON`, `draft`, `placeholder`,
      `lorem`); or it is byte-identical to another unit's canDo. Run the
      duplicate check as a query:
```sql
select body->>'canDo' as can_do, count(*)::int as n,
       string_agg(body->>'id', ', ' order by body->>'id') as unit_ids
from content_units
where kind = 'curriculum_unit'
group by 1
having count(*) > 1
order by 2 desc;
```
