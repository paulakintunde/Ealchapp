<what_is_actually_true_today>
Measured in the repo on 2026-09-25, not taken from a summary:

- `ealch-v2/src/store/entitlement.logic.ts:34` lists `'examiner'` in FEATURES. `PREMIERE_FEATURES` (line 41) deliberately excludes it, and `featuresForPlan` returns only Première features, so no plan grants it.
- The only grant path is `entitlementFromProfile` (line 391): an active `profile.accessLevels['exam']` (`ACCESS_LEVEL_EXAM`, line 346) pushes `'examiner'` onto the feature list (line 398).
- Live `entitlements` and `subscriptions` are both 0 rows (plan 08 checked). No account can hold it, and `aking.akint@gmail.com` cannot be made to carry it without a real Adapty purchase.
- Faking it on the device does not work: Adapty's own SDK cache overrides an injected AsyncStorage entitlement and wins on relaunch, even offline. So there is no device-side shortcut.
- `examGateOn` defaults to `false` in `ealch-v2/src/services/config.ts:102`; `examFreePapers` is `1` (line 103). Plan 08 flipped the live `system_config` value true for its test and restored it to `false`.
- `examPaperAllowed` (`ealch-v2/src/utils/examGate.logic.ts`) already has pure unit coverage for the entitled branch (`examGate.logic.test.ts:24`).
- Both screens read the real entitlement: `exam.tsx:57` and `exam-paper.tsx:68` both call `useFeature('examiner')`, and both pass it to `examPaperAllowed`. But the only tests asserting that wiring are source-grep tests (`examSection.logic.test.ts:593`, `examAttemptWiring.test.ts:18`), which would still pass if the composed chain were broken.

So the honest residual gap is narrow: the pure gate and the screen wiring are covered, but nothing proves the *composition* — an Adapty-shaped profile turning into an entitlement that the gate then honours. That is the gap this plan closes in code, and it is exactly the part a store purchase is not needed for.
</what_is_actually_true_today>

<why_flipping_the_gate_on_now_would_be_wrong>
With `examGateOn: true` and `examFreePapers: 1`, papers 2 and up return `needs-exam-tier` and route to the paywall. Nobody can hold `examiner`, and there is no purchasable exam product wired: `ACCESS_LEVEL_EXAM` has no product or paywall behind it yet. Every blocked candidate would reach a paywall that cannot sell them the thing it is blocking. That is worse than either end state, so the flip has a real precondition, not just an owner.
</why_flipping_the_gate_on_now_would_be_wrong>
