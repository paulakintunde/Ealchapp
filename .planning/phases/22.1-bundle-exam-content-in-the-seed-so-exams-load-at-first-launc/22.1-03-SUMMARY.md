# Phase 22.1 Plan 03: Correct stale seed/exam comments outside plans 02 and 04 Summary

Rewrote seven comment-only locations (five app/service files, two test rationale blocks) that previously asserted "exam content ships ONLY in the OTA snapshot, never the seed" — a claim plan 22.1's seed-cut change makes false — while preserving the surrounding, still-true explanation of why the corpus is a real dependency and why `report-reachable.test.ts` must stay in `ealch-admin`.

## What Was Built

**Task 1 — App/service comment corrections (`content.ts`, `exam.tsx`, `exam-paper.tsx`, `exam-report.tsx`, `home.tsx`):**
- `content.ts` (~L20-25): the v66 27MB AsyncStorage-incident comment now says exam content "before phase 22.1 reached the app through the snapshot alone", past tense, outside the stale-phrase gate. The candidate-facing history ("saw 'no exams available yet'") is kept as history.
- `content.ts` (~L159-167): the dev-fixture-removal paragraph is kept unchanged; the second paragraph ("A fresh offline install therefore has NO exam content... by design") is replaced with a present-tense statement that `content:publish` now bundles every published exam paper plus its referenced tasks into the seed cut since phase 22.1, audio still resolves from Storage by `audioRef`, grading still needs the network, and the snapshot still supersedes bundled papers by id via `mergeCorpus`. The "never show an unreviewed mock paper" point is kept.
- `exam.tsx` (~L63-69): "the corpus ALWAYS changes... exam content ships only in the OTA snapshot (never the seed)" is replaced with "the corpus still changes after this screen can mount, because the seed's bundled papers (phase 22.1) are superseded by the OTA snapshot a few seconds into launch, and a paper corrected after release arrives that way" — the dependency rationale (`content.*` reaches into the store via `getState()`, so the corpus must be a real `useMemo` dependency) is unchanged.
- `exam-paper.tsx`, `exam-report.tsx`, `home.tsx`: the shared 5-line block's final sentence is replaced with "Before phase 22.1 exam content reached the app only through that snapshot, so an exam screen mounted during launch memoised an empty result and kept it; the seed now carries the papers, and the snapshot can still supersede them after mount." The "see the note in app/exam.tsx" cross-reference is unchanged in all three files.

**Task 2 — Test rationale corrections (`contentCache.test.ts`, `report-reachable.test.ts`):**
- `contentCache.test.ts` L16 and L64 (v66 incident history comments): both "exam content ships ONLY in the snapshot" clauses rewritten to past tense ("since before phase 22.1 exam content reached the app through the snapshot alone" / "which before phase 22.1 came only over the air"). Assertions untouched — this file statically parses `content.ts`'s source, so no logic depends on these comments.
- `report-reachable.test.ts` "Why in ealch-admin" block (~L25-32): per D-11, the test stays in `ealch-admin`. The stated reason is corrected from "exam content is deliberately NOT in seed.json ... exams do not ship offline (exam-pack decision 11.6)" to "this is the only repo that can see ALL published papers in Postgres alongside the reporting logic ... the seed is a cut and cannot vouch for a paper Postgres holds that the cut did not ship" and now references `ealch-v2`'s forthcoming `exam-ships.test.ts` (plan 02/04 territory) as the seed-side counterpart. No assertion change.
