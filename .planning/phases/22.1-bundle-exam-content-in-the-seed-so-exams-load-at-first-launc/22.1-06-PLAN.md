<cold_start_method>
The ONE method used before (this plan) and after (plan 08). Seed-only on purpose: airplane mode from before first launch means no snapshot is downloaded or cached, so the timing measures the bundled seed import that this phase grows.
1. `adb uninstall app.ealch.mobile` (ignore "not installed"), `adb install <apk>`.
2. `adb shell cmd connectivity airplane-mode enable` BEFORE the first launch.
3. Warm-up: `am start -W -n $ACT`, wait 10 s, `am force-stop $PKG` (discarded).
4. Eight runs: `am force-stop $PKG; sleep 3; am start -W -n $ACT`, parse `TotalTime`. Discard run 1; report the median of runs 2-8 and the min/max.
5. Record device model (`getprop ro.product.model`), Android version, build id, commit.
</cold_start_method>
